# 离线量化研究与纸面订单实验

环境要求：Python 3.12+ 标准库，无网络请求、无券商账号、无 API Token。

运行：
    python3 examples/quant_lab.py
    python3 -m unittest discover -s examples -p 'test_*.py' -v

第23章对应信息可用时点、财报修订与拆股复权；第24章对应移动窗口热身、收盘后生成信号、次日开盘执行、交易费和滑点；第25章对应订单幂等、风险闸门、部分成交、撤单状态。

所有金额、交易日与价格均为构造值。PaperBroker 是内存状态机，不连接任何真实券商或交易所。next_open_backtest 每次只交易一股，初始现金1000元，并非真实撮合或容量模型；不包含税费、股息、停牌、涨跌停、融资融券、真实成交量。复权函数只演示供应商累计因子的基准变换，不等于含分红再投资的总回报。

Pandas、NumPy和TA-Lib见教程正文，均为可选扩展；上述最小示例的自动化测试无额外依赖。
